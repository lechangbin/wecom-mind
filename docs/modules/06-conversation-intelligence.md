# 06. 会话智能模块

## 1. 模块职责

会话智能模块负责将群聊消息切分成可理解的主题会话，并保存摘要和结构化信息。

负责：

- 选择待分析消息窗口。
- 生成候选切分边界。
- 调用 `conversation_segmentation` Dify 工作流。
- 校验 Dify 返回边界。
- 生成或确认会话编号。
- 写入会话切分和摘要。
- 支持重跑和版本更新。

不负责：

- 原始消息入库。
- Dify Prompt 编排。
- 用户画像事实生成。

## 2. 输入输出

输入：

- chatid。
- 时间范围。
- 消息列表。
- 上一个会话摘要。
- 候选边界。

输出：

- `conversation_segments`
- 会话标题。
- 起止消息。
- 摘要。
- 关键词。
- 参与人。
- 置信度。

## 3. 候选切分策略

自建系统先做轻量候选切分：

- 超过一定时间无消息。
- 消息数量超过窗口阈值。
- 明显话题切换关键词。
- 上一会话已经结束。

Dify 负责语义确认，不负责凭空创造不存在的边界。

## 4. 处理流程

1. 调度器选择 chatid 和时间窗口。
2. 查询未切分或待重跑消息。
3. 生成候选边界。
4. 调用 Dify Gateway。
5. 校验 Dify 输出。
6. 生成 `conversation_no`。
7. 写入 `conversation_segments`。
8. 标记旧版本为 `superseded`。

## 5. 校验规则

必须校验：

- `start_msgid` 存在。
- `end_msgid` 存在。
- 起始时间早于结束时间。
- 会话区间不交叉。
- participants 来自消息发送人。
- summary 非空。

## 6. MVP 实现范围

必须实现：

- 手动或定时触发会话切分。
- 调用 Dify。
- 保存切分结果。
- 查询会话摘要。

可延后：

- 复杂版本对比。
- 人工修正会话边界。
- 会话质量评分。

## 7. 验收标准

- 一段消息能生成至少一个会话段。
- 会话段有编号、标题、摘要、起止消息。
- Dify 返回非法边界时不会写库。
- 重跑后能保留版本记录。
